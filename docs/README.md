# vue-plot-docs

> Documentation site for [@memotux/vue-plot](../README.md). Built with [Docus](https://docus.dev) (Nuxt 4 + Nuxt UI). This folder is the `docs` workspace inside the pnpm monorepo.

This site is a static Nuxt 4 application. Content lives in `content/` as Markdown + MDC and is statically generated by `nuxt generate`. It is the `vue-plot-docs` private workspace of the `@memotux/vue-plot` monorepo.

For the library API, installation, and usage, see the [project README](../README.md). This README documents the **docs site itself** — how to run it, author content, and ship it.

## Run the site locally

From the monorepo root:

```bash
pnpm install
pnpm --filter vue-plot-docs dev
```

Or from this folder:

```bash
pnpm install
pnpm dev
```

The dev server runs at <http://localhost:3000> with HMR for Markdown, MDC components, and theme changes.

## Scripts

| Script | Command | Purpose |
| --- | --- | --- |
| `dev` | `nuxt dev` | Local dev server with HMR |
| `build` | `nuxt build` | Build the production server |
| `generate` | `nuxt generate` | Statically generate the site to `.output/public/` |
| `preview` | `nuxt preview` | Preview the production build |

## Author content

### Section layout

Pages are grouped into three numbered sections. Use the existing folders — the numbering controls sidebar order.

| Section | Folder | Purpose | Page titles |
| --- | --- | --- | --- |
| Getting Started | `1.getting-started/` | Install and first steps | Noun: `introduction`, `installation`, `setup` |
| Guide | `2.guide/` | How-tos and patterns | Topic: `marks-as-children`, `reactive-data`, `nuxt-integration` |
| API Reference | `3.api/` | Component / type reference | Symbol: `vplot`, `mark-components`, `types` |

Each section folder has a `.navigation.yml` that controls its sidebar label and collapsed state.

### File naming

Use a numeric prefix to order pages within a section:

```text
1.getting-started/
  1.introduction.md
  2.installation.md
  3.setup.md
```

### Frontmatter

Every page declares at least a `title` and `description`. The landing page and section indexes add an `seo` block for the `<title>` and meta description:

```md
---
title: Introduction
description: What Vue Plot is and its two usage patterns.
seo:
  title: Introduction — Vue Plot
  description: ...
---
```

### MDC components

Docus renders Nuxt UI components through MDC. **Always prefix Nuxt UI components with `u-`** — without the prefix, Vue fails to resolve the component.

```md
::u-page-hero    ✅ resolves to UPageHero
::page-hero      ❌ fails to resolve
```

Commonly used: `u-page-hero`, `u-page-section`, `u-page-feature`, `u-page-grid`, `u-page-card`, `u-page-cta`, `u-button`. Full list at <https://ui.nuxt.com>.

### Headings and voice

- H2/H3 headings use **action verbs**: "Configure Vite", not "Configuration".
- Use active voice and present tense.
- Add a file-path label to code blocks: ```` ```ts [vite.config.ts] ````.
- For commands available in multiple package managers, wrap them in `::code-group` and show `pnpm` first (the monorepo uses pnpm).

## Theming

Site metadata and colors live in `app/app.config.ts`. The site uses a Kanagawa palette:

```ts
ui: {
  colors: {
    primary: 'dragon-yellow',
    secondary: 'dragon-blue-2',
    // ...
  }
}
```

Code blocks use the `kanagawa-dragon` (dark) and `kanagawa-lotus` (light) Shiki themes — change them in `nuxt.config.ts` under `mdc.highlight.theme`.

Custom components (header logo, app icon, etc.) live in `app/components/`. Nuxt auto-imports them, so they are usable in `app.vue` without an explicit import.

## Deployment

The site is built as a fully static Nuxt 4 app:

```bash
pnpm generate
```

Output goes to `.output/public/` and can be deployed to any static host (Vercel, Netlify, Cloudflare Pages, GitHub Pages). The top-level routes (`/getting-started`, `/guide`, `/api`) are prerendered explicitly in `nuxt.config.ts` under `routeRules`.
