Install Vue Plot and its peer dependency:

::code-group

```bash [pnpm]
pnpm add @memotux/vue-plot @observablehq/plot
```

```bash [npm]
npm install @memotux/vue-plot @observablehq/plot
```

```bash [yarn]
yarn add @memotux/vue-plot @observablehq/plot
```

::

::warning
`@observablehq/plot` is a **required peer dependency**. It is NOT bundled with Vue Plot — you must install it separately.
::

## Verify installation

After installing, verify both packages are present:

```bash [terminal]
ls node_modules/@memotux/vue-plot
ls node_modules/@observablehq/plot
```

## Package versions

| Package | Minimum Version |
|---------|-----------------|
| `@memotux/vue-plot` | `0.4.2` |
| `@observablehq/plot` | `0.6.17` |
| `vue` | `3.5.0` |
